# Linear Regression Case Study

Minimal project scaffold for:

- Exploratory data analysis (EDA)
- Data preprocessing
- Feature engineering
- Linear regression modeling

## Structure

```text
.
├── data/
│   ├── raw/          # Original input data
│   └── processed/    # Cleaned or transformed datasets
├── notebooks/        # EDA and experimentation notebooks
├── reports/          # Exported figures, notes, or summaries
└── src/              # Reusable Python code
```

## Suggested workflow

1. Put the source dataset in `data/raw/`.
2. Do initial exploration in `notebooks/`.
3. Move reusable preprocessing or feature logic into `src/`.
4. Save cleaned datasets in `data/processed/`.
5. Store charts or writeups in `reports/`.
